隐私政策 / Privacy Policy (Minimal)

概述
- 本项目默认不采集任何遥测数据，不主动向外发送使用数据或代码片段。
- 仅在本地工作区生成 `.mcp/` 目录下的状态与报告文件（例如覆盖率、规则快照、计划与记忆等），用于本地或 CI 产物审阅。

可选的第三方服务
- Codecov：仅在 CI 环境中（公共仓库默认）上传覆盖率报告以便可视化浏览；私有仓库需显式配置 `CODECOV_TOKEN` 才会上传。
- 包仓库与应用商店：当从 PyPI/VS Code 市场安装或升级时，将与对应商店发生网络交互；其隐私政策以商店条款为准。

本地权限与安全
- CLI/Server 默认在当前工作区读写 `.mcp/` 下的文件；不会访问用户主目录下的隐私文件，除非用户显式传入路径或启用许可激活（读取/写入 `~/.mcp/license.json`）。
- 在示例 Dockerfile 与 CI 中，采用最小化镜像与固定版本的安全工具（bandit/semgrep/hadolint）。

数据保留
- `.mcp/` 目录下的产物留存在你的仓库或工作目录中；可通过 `mcp-rules-assistant cleanup` 或 `.gitignore` 进行清理/排除。

联系与申诉
- 联系邮箱：support@ruleflow.app
- 如你在使用过程中发现潜在的隐私风险或异常网络访问，请通过 Issue 或安全私信渠道与我们联系，我们将在 3 个工作日内响应。
