# Release v0.2.6 — Docs/CI Consistency & Cleanup (Draft)

本次版本为“工程维护与一致性”更新，聚焦于文档归档、CI 近阈值导出、测试/清理体验优化，不涉及 API 变更。

## Highlights
- 文档归档：将 AI 协作交接与状态索引移至 `docs/AI_*.md`，入口统一由 README/DEVELOPMENT 指向。
- 清理说明：在 `DEVELOPMENT.md` 与 `docs/CONTRIBUTING.md` 新增“清理与还原环境”，明确一键清理与可安全清空的目录。
- VS Code 覆盖率近阈值：CI 导出 `near_vscode.txt` 工件并展示前 50 行，便于快速补测。
- macOS 稳定性：`make vscode-test` 在 macOS 默认走容器，提高本地无头测试稳定性。
- 钩子阶段：自定义 pre-commit 钩子统一迁移至 `pre-push`，消除未来弃用警告。

## Quality Gates
- Python：核心≥98%，其余≥95%，weak=[]；`-W error`；禁止 skip/xfail（包内）。
- VS Code：CI 硬门禁≥98%，near/worst 工件输出（job: `vscode`）。
