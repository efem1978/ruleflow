# 定价与许可 / Pricing & Licensing

计费与税务（MoR）
- 使用代商（MoR）平台（如 Lemon Squeezy / Paddle）作为卖方，自动处理全球 VAT/GST/发票与合规。
- 以 USD 计价；平台自动本地化展示与结算（支持 EUR/GBP/CNY 等显示）。
- 平台按成交抽成（无前置费用），具体费率以官网为准（常见为“按比例 + 固定额/笔”）。

订阅（推荐）
- MSRP（标价）：
  - 个人：$12/月 或 $119/年
  - 团队（3–9 席）：$15/席/月 或 $150/席/年
  - 商业（10–49 席）：$19/席/月 或 $190/席/年
  - 企业（50+）：定制（含 SLA/私有交付）

启动促销（建议）
- 上线首 60 天：在 MoR 平台发券或限时折扣，约 30–40% OFF（例如个人 $7.2/月、$69/年；团队 $9/席/月；商业 $12/席/月）
- 企业（50+）：定制（含 SLA/私有交付）

一次性买断（可选附加）
- 个人：$249 一次性（含 12 个月更新与支持）
- 团队：$399/席 一次性（含 12 个月更新与支持）

说明
- 团队/企业席位价略高，反映多用户价值、协作增益与支持成本；梯度收敛，便于接受与预算审批。
- 年付相当于“月付 × 约 10”，内含 1–2 个月折扣（行业常见做法）。
- 买断价通常为年费的 2.5–3.5 倍，含当年更新，后续可选续保。

能力范围（与付费权益）
- 规则摄取/冲突与建议/覆盖率（弱项/分组/近阈值）
- VS Code 面板（状态栏入口 + 自然语言输入 + 历史/范例）
- IDE 内自然语言触发（命令“RuleFlow: Natural Command”/面板输入/可选 Copilot 登记）
- CI/Hooks 生成与校验、受控写入（fs.apply_patch）
- 诊断/一键打包（后续）

试用与激活
- 7 天完整功能试用（离线可用）；到期后需导入许可证（离线激活）。
- 许可证文件（演示/示例）：`~/.mcp/license.json` 或 项目内 `.mcp/license.json`
  - 示例：`{"product":"ruleflow","email":"you@example.com","type":"pro","expires":"2026-12-31"}`
- CLI（示例）：
  - 查看状态：`mcp-rules-assistant license-status`
  - 离线激活：`mcp-rules-assistant license-activate --file path/to/license.json`

隐私与合规
- 默认无遥测；状态与工件写入 `.mcp/`（本地优先）。
- 企业协议可选：私有化交付、离线环境合规、SLA 与数据处理协议（DPA）。

当前阶段（内测）
- 暂不对外收费，定价与促销用于备战公测/首发；以 README 与站内说明为准。
