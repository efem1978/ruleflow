# 项目全面审查清单 / Project Comprehensive Audit Checklist

**版本**: v1.0  
**创建日期**: 2025-10-03  
**审查目的**: 商业化发布前的生产级质量保障  
**审查模式**: TDD 驱动，测试优先

---

## 📋 审查优先级与顺序说明

**目标用户**: 编程小白  
**核心使命**: 通过强制约束AI行为，帮助小白高质量编程

基于 TDD 模式和初始需求，审查顺序必须遵循：

0. **初始需求覆盖度**（P-1 - 前置检查）- 确保核心功能实现
1. **测试与覆盖率**（P0 - 最高优先级）- 测试不通过则无法确认开发进度
2. **代码质量**（P1）- 静态分析与规范检查
3. **文档完整性**（P2）- 文档与代码一致性
4. **生产级标准**（P3）- 安全、性能、可维护性
5. **商业化准备**（P4）- 发布、许可、合规
6. **小白友好性**（P5 - 用户体验）- 自然语言、易用性

## P0 - 测试与覆盖率审查（最高优先级）

### 0.1 测试执行与通过率

**检查命令**:
```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 pytest -q -p pytest_cov --maxfail=1 --disable-warnings -W error --strict-markers --cov=mcp_rules_assistant --cov-report=xml:coverage.xml --cov-report=term-missing
```

- [ ] **所有测试全绿通过**（零失败）
- [ ] **零跳过测试**（禁止 `skip`/`xfail`/`only`/`focus`）
- [ ] **零警告**（`-W error` 模式下）
- [ ] **零 Flaky 测试**（多次运行结果一致）
- [ ] **测试日志零警告**（检查测试输出）

**检查方法**:
```bash
# 运行 3 次确保稳定性
for i in {1..3}; do
  echo "Run $i"
  make test || exit 1
done
```

### 0.2 覆盖率阈值检查

**检查命令**:
```bash
mcp-rules-assistant coverage-report --json > cov_audit.json
cat cov_audit.json | jq '.weak'
cat cov_audit.json | jq '.near'
```

- [ ] **核心模块 ≥98%** (`.mcp/assistant.yaml` 中 `coverage.min_core`)
  - `mcp_server.py`
  - `cli.py`
  - `config.py`
  - `progress.py`
  - `tools.py`
  - `memory.py`
  - `server.py`
- [ ] **非核心模块 ≥95%** (`coverage.min_module`)
- [ ] **弱项清单为空** (`weak = []`)
- [ ] **近阈值清单为空或可接受** (`near` 窗口以配置为准)
- [ ] **覆盖率策略完整** (`.mcp/assistant.yaml` 的 `coverage.policy` 已配置)

**详细检查**:
```bash

mcp-rules-assistant coverage --top 50

# 查看分组覆盖率
mcp-rules-assistant coverage-groups

# 查看目录树覆盖率
mcp-rules-assistant coverage-tree

# 查看近阈值文件
mcp-rules-assistant coverage-near --within 3 --top 20
```

### 0.3 测试质量审查（防作弊/偷懒）

- [ ] **测试难度未降低**
  - 检查测试用例是否覆盖完整业务流程
  - 避免仅测试简单路径
  - 确保异常分支有测试
  
- [ ] **断言充分且严格**
  - 避免空断言或弱断言（`assert True`）
  - 检查返回值、状态变化、副作用
  - 使用精确匹配而非模糊匹配

- [ ] **无拆分作弊**
  - 整体工作流测试必须通过
  - 避免仅拆分后的单元测试通过，整体失败
  - 集成测试覆盖完整链路

- [ ] **测试数据真实性**
  - 使用真实场景数据
  - 边界值测试完整
  - 异常输入有覆盖

**检查脚本**:
```bash
# 检查是否有 skip/xfail
git grep -n "pytest.mark.skip\|pytest.mark.xfail\|@skip\|@xfail" tests/ && echo "❌ 发现跳过标记" || echo "✅ 无跳过标记"

# 检查空断言
git grep -n "assert True\|assert False\|pass$" tests/ | grep -v "# " && echo "⚠️ 发现可疑断言" || echo "✅ 断言检查通过"
```
