# Python 后端（BDD 标准）规则包

## 目标

- 行为驱动开发（BDD）作为主流程：需求→特性→场景→实现→验证。
- 核心路径高质量：覆盖率≥90%，核心模块≥95%。
- 可读、可维护、可回滚、可观测。

## 最低门槛（建议）

- 覆盖率：整体≥0.90，核心模块≥0.95；禁止下调阈值。
- 测试风格：pytest + behave/pytest-bdd（二选一）。
- 断言质量：禁止弱断言；避免过度打桩。
- 日志：结构化，不输出敏感信息。
- Lint/格式化：ruff + black；类型（mypy）按需开启。

## 测试与用例

- 用例组织：
  - features/*.feature 描述业务场景（Given/When/Then）。
  - tests/ 单元与集成测试并存；禁止跳过（skip/x{fail}/only/focus）。
- 固定随机种子；避免 Flaky；CI 与本地一致。

## CI 门禁（建议）

- 通过步骤：Lint/Type → 测试 → 覆盖率门禁 → 安全扫描 → 构建。
- 产物可追溯：Tag/签名/构建信息；失败即阻断发布。

## 回滚与观测

- 提供简明可执行回滚脚本；
- 关键指标/日志/追踪按需接入；严重错误留痕。
