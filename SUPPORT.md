- **GitHub Issues**: [Report bugs or request features](https://github.com/efem1978/Contextual-Cohesion-and-Programming-Rules-Assistant-MCP-Tool/issues)

### 🐛 Reporting Bugs

Please include:
1. **Environment**: OS, Python version, installation method
2. **Steps to reproduce**: Exact commands or actions
3. **Expected behavior**: What should happen
4. **Actual behavior**: What actually happens
5. **Logs**: Relevant error messages or stack traces

### 💡 Feature Requests

We welcome feature requests! Please:
1. Check existing issues to avoid duplicates
2. Describe the problem you're trying to solve
3. Explain your proposed solution
4. Provide use cases if applicable

### 🔒 Security Issues

For security vulnerabilities, please **DO NOT** open a public issue. Instead, report to:
- **Email**: support@ruleflow.app
- See [SECURITY.md](SECURITY.md) for details

### ❓ FAQ

**Q: How do I install the tool?**  
A: Run `bash install.sh` (Linux/macOS) or `install.bat` (Windows). See [README.md](README.md) for details.

**Q: Which IDEs are supported?**  
A: VS Code, Cursor, Windsurf (full support). JetBrains, Neovim, Sublime (community extensions).

**Q: Is telemetry collected?**  
A: No. All data is stored locally. See [SECURITY.md](SECURITY.md).

**Q: Can I use this commercially?**  
A: Yes! This project is MIT licensed. See [LICENSE](LICENSE).

**Q: How do I contribute?**  
A: See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines.
